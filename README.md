# Customer Segmentation Using Clustering Algorithms

## Project Overview

This project presents a complete end-to-end Customer Segmentation pipeline using Unsupervised Machine Learning techniques.

The main objective is to discover meaningful customer groups based on purchasing behavior, demographics, and marketing interactions. Three clustering algorithms are implemented and compared to identify the most suitable model for the dataset.

---

## Objectives

- Perform comprehensive customer segmentation.
- Compare multiple clustering algorithms.
- Evaluate clustering quality using multiple metrics.
- Visualize customer segments.
- Generate business insights and recommendations.

---

## Dataset

Customer Personality Analysis Dataset

The dataset contains customer demographic information, purchasing behavior, campaign responses, income, spending patterns, and customer relationship history.

Dataset Source:

https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis/code

## Results

The project successfully identified meaningful customer segments with distinct characteristics.

The comparison between multiple clustering algorithms demonstrated that K-Means achieved the best overall performance for this dataset based on internal clustering evaluation metrics.
